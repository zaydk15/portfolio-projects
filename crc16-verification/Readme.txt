Guidelines to Execute the Project


-> Copy the folders (dut, tb, & sim) to your QuestaSim server.

-> Change directory to the /sim/ folder:
   cd sim/

-> Run the following command in the terminal window:
	>> vsim
	(QuestaSim will be opened)

-> Run the following command Under Transcript Window in QuestaSim:
	> do run.do
	(This will automatically compile all .sv files and launch simulation.)
